### 环境事件（重要，后续会话别再踩）
- **git 无法建分支/提交**：报 `cannot lock ref ... Permission denied`。根因不是 DSH 沙箱模式，而是
  Windows 文件权限：`F:\DKD\.git` 的 ACL **禁用了继承**，工作区根上给受限访问用的 SID 授权
  （`S-1-4-...`）传不进 `.git`，导致写 refs/index/objects 全被拒。用 `diagnose-windows-sandbox-acl`
  技能的一条命令修复（给当前登录用户补 FullControl，保留 deny/owner，并打印回滚命令）。
  - 修复回滚命令：`pwsh -NoProfile -File 'F:\acl-recovery\acl-backup-a2adc33c5a154f69a839bbfd184f9b5a.json.ps1' -Path 'F:\DKD\.git' -AllowRoot 'F:\DKD' -Restore 'F:\acl-recovery\acl-backup-a2adc33c5a154f69a839bbfd184f9b5a.json'`
  - 报告：`F:\acl-recovery\acl-report-b96320b6ac8444929c8a1db6cbb6969a.jsonl`
  - 教训：**.git 一旦被上一代沙箱工具改过 ACL（本次可见 `CodexSandboxUsers` 残留组），后续任何
    agent 的 commit 都会失败**，且报错是 Windows 权限而非 git 语义，先怀疑 ACL 再看 git。
