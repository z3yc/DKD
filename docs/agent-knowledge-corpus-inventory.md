## 2. L2 切片与检索建议（3-6 开工时照此实现）

| 项 | 建议 | 理由 |
| --- | --- | --- |
| 切片单位 | 按**语义章节**切（标题/步骤/故障码行），不按固定字数硬切 | 硬切会把“现象”和“处置”切散，检索出来只剩半句 |
| 片长 | 300~500 字；overlap 50~80 字 | 太短丢上下文，太长稀释相似度 |
| 片头 | 保留「文档名 §章节」作为片头 | 引用时能回答“这条依据来自哪一页/哪一节” |
| 故障码表 | **一行一码**结构化切片（码值+含义+建议动作） | 表格型语料按文本切会产生跨行错位 |
| 检索 top-k | 先取 top-8 再阈值过滤，最终引用 ≤3 条 | 引用太多运营不看，太少容易误判 |
| 引用强制校验 | 结论中的每条断言必须绑定相似度 ≥ 阈值的片段；绑定不上 → 回退「仅列证据」模板 | 3-6 验收项：无引用断言的结论 **100% 被回退**（排期 3-6） |
| 检索测试 | 每个语料至少 3 个问题的人工检索测试（命中/未命中/误导） | 3-6 交付物「检索测试报告」 |
| 命中归因 | 记录近 7 日命中/采纳次数（3-6 配套） | 不改善的语料应下线，不硬撑（计划表 R11） |
