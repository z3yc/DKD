## 1. 一句话

**一套给自动售货机运营商用的「设备资产 + 作业 + 交易 + 报表」管理平台**，并在旁路挂了
**可配置、可审计、可评测的智能体（LLM）能力层**：补货建议、故障诊断、知识库检索、
外部只读 MCP 工具、自然语言问数，所有 AI 决策留痕可回放；主业务永远有原规则链路兜底。

## 2. 解决什么问题

| 问题 | 平台给的能力 |
| --- | --- |
| **货卖得怎么样？** | 订单/营收报表、区域与设备排行、AI 日报解读 |
| **什么时候该补货？** | 库存预警 + 规则版建议 + **智能体补货建议**（7/14/30 天分位销量 + LLM 校准；校准不可用时明确标「未校准」） |
| **设备坏了怎么办？** | 多轮诊断（证据/未知项/平台动作/置信度，刻意不含病因）→ 人工确认建维修工单 |
| **知识/手册在哪？** | 知识库 L2：文档入库→切片→本地向量检索→**回答强制引用 `[KB:docCode]`**；无命中回退“未覆盖/仅列证据” |
| **谁在干活、干得怎样？** | 工单状态机、运维端接单/完成、员工排名、决策审计、运营驾驶舱 |
| **怎么安全地交给运营？** | 配置台（prompt/工具/模型/知识库/MCP）+ 评测护栏 + 灰度手册 + 告警 runbook + 安全复核 |

| 角色 | 主要在哪个端 | 典型操作 |
| --- | --- | --- |
| 运营管理员 | 管理后台（Web） | 建区域/点位/设备、配货道与商品、看报表、审 AI 建议、配置智能体/工具/知识库/MCP |
| 运维/维修工程师 | 运维移动端（`dkd-app`，H5/App） | 接单、完成（补货/维修/投放/撤机）、查设备 |

| 平台/开发运维 | 配置与部署 | `agent.enabled` 开关、灰度放量、告警处置、凭据轮换、CI 与演练 |

## 4. 系统组成（四个端 + 一条可配置旁路）

```
        ┌──────────────── 管理前端 dkd-vue（Vue3 + Element Plus，:80）────────────────┐
        │ 业务页面（设备/点位/商品/订单/工单/报表…） + AI 助手抽屉（SSE 流式）         │
        │ AI 智能体菜单（11 个）：补货工作台/决策审计/运行时间线/智能体配置/执行日志/   │
        │ 历史会话/工具中心/模型档案/知识库/MCP 接入/运营驾驶舱                        │
        └──────────────────────────────┬──────────────────────────────────────────────┘
                                       │ /prod-api 反代
        ┌──────────────────────────────▼──────────────────────────────────────────────┐
        │ 管理后台 dkd-parent（Java 8，Spring Boot 2.5，:8080）                        │
        │ dkd-admin · dkd-framework · dkd-system · dkd-manage · dkd-common ·          │
        │ dkd-quartz · dkd-generator；新增 Agent 配置/工具/模型/知识库/MCP/评测/驾驶舱  │
        └───────┬──────────────────────────────────┬──────────────────────────────────┘
                │ 共用 dkd MySQL 库                 │ /agent/** 网关（JWT + 权限点 + SSE）
        ┌───────▼──────────────┐        ┌───────────▼──────────────────────────────────┐
        │ 运维移动端 dkd-app    │        │ 智能体服务 dkd-agent（Python 3.11/FastAPI/    │
        │（Java 11，:9070）     │        │ LangGraph，:8090，只监听回环）                 │
        │ 接单/完成/查设备      │        │ 补货图/诊断图/助手/知识库/MCP/日志/评测       │
        └──────────────────────┘        └───────────┬──────────────────────────────────┘
                                                    │ 只读业务表（白名单）+ 写 agent_* 自有表
                                                    │ 业务写操作 → 回调 Java REST（服务间密钥）
```

**关键边界（设计红线，仍有效）**
- **Java 是业务事实唯一所有者**：所有业务写操作必须经 Java 校验链与事务；
- 智能体**只读**业务表（MySQL 只读账号 + 表名白名单双向校验）；写操作一律回调 Java（人工确认）；
- 智能体自有表 `agent_*` 由 Agent 自维护，**不授 DELETE**；`agent_config/agent_tool/agent_llm_profile`
  等配置由 Java 写、Python 只读（MCP 同步/状态回写为已登记例外）；
- **LLM 不可信**：结构化输出容错解析 + 范围夹取；写操作必须 human-in-the-loop；
- `agent.enabled=false` 或 Python 不可用时，主业务零影响（旧单轮 AI 兜底 + 前端降级）。

## 5. 功能地图（按业务域）

### 5.1 组织与档案
区域 / 点位（含商圈类型、Excel 导入、AI 选址）、合作商、员工与角色、系统管理。

### 5.2 设备与商品
设备型号（自动生成货道）、售货机台账、货道、商品/分类、策略（预留）。

### 5.3 交易与库存
订单查询/详情/导出/取消/退款（仓外系统写入，平台全快照只读 + 两个动作）；
库存台账/流水；订单出货成功回写库存并写流水。

### 5.4 作业（工单）
四类工单（投放/补货/维修/撤机）；统一建单校验链；状态机；运维端接单/取消/完成。

### 5.5 报表与决策
日报/周报 + AI 解读（失败降级纯数据）+ 排行；库存预警；规则版补货建议（85% 容量、2×预警）。

### 5.6 智能体能力（已从“旁路助手”升级为“可配置能力层”）

| 能力 | 当前实现 |
| --- | --- |
| **补货 Agent** | 06:00/手动分析 → 7/14/30 天分位销量 + 容量约束 → LLM 校准系数（失败降级统计基线）→ 计划；工作台确认/调整/跳过/暂停；`llm_calibrated` 三态标「未校准」 |
| **诊断 Agent** | 多轮问诊（焦点设备状态）+ 异常/历史线索 + 结构化结论（证据/未知项/动作/置信度，不含病因）→ 人工派单 |
| **知识库 L2（S11）** | 文档入库（同内容 hash 跳过、增量不双写）→ 句界切片 → 本地哈希向量检索 → `agent_kb_retrieval` 留痕；回答强制引用；无命中回退“未覆盖/仅列证据” |
| **MCP 接入（S12）** | HTTP JSON-RPC；**只读工具硬闸**（`readOnlyHint` 必须 true）、超时≤5s、行数≤200、密钥只存 env 名；启动探测失败拒绝启动；当前仅 http、工具注入诊断场景 |
| **配置台（S3/S4/S14）** | prompt 编辑（占位符白名单/版本 diff/回滚）、自定义 chat 智能体（scene≥101）、工具中心启停、模型档案（只存 `api_key_env`，连通测试写探测记录） |
| **会话与历史（S13）** | `agent_conversation` + `agent_message`（user+assistant、configVersion、工具耗时/行数）、刷新恢复、历史会话详情、requestId 跳日志 |
| **执行日志/运行时间线** | `agent_log`（Handler 批量写）、`agent_run/agent_step/agent_tool_call` 运行时间线 |
| **评测护栏（5-1）** | 离线/在线评测脚本 + CI；只有 `verified` 用例进准确率；无样本输出 **BLOCKED**；配置保存可开启评测护栏（409 + force 留痕） |
| **运营驾驶舱（6-1）** | 采纳/未校准/成本/失败四卡 + 告警条 + 待我处理 + Agent vs 规则（n=0 明确“样本不足”） |
| **监控告警（6-2）** | 八类检查脚本（ERROR 突发/连续失败/06:00 失败/模型探测/MCP/未校准/KB 回退/待指派超时）+ runbook |
| **AI 助手** | 全局抽屉；场景由配置下发（内置 2/3/4 + 自定义 ≥101）；SSE 逐 token、中断、续传、降级 |

## 6. 四条核心闭环

1. **补货闭环**：库存预警 →（规则版/Agent）建议 → 工作台人工确认 → 建补货工单 → 运维接单完成（同事务写库存）。
2. **故障闭环**：设备异常 → 诊断（证据/未知项/置信度）→ 派单提案 → 人工确认 → 维修工单 → 运维维修。
3. **知识引用闭环**：文档入库 → 检索 → 回答必须带 `[KB:docCode]` → 无命中/无引用回退“仅列证据” → 检索留痕可监控回退率。
4. **审计与评测闭环**：AI 决策 → `agent_decision_log`/`agent_message` → 审计页/驾驶舱 → 评测集与 CI → 配置护栏 → 灰度/回滚。

## 7. 技术架构要点

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 前端 | Vue 3.4 + Element Plus + Vite（**JavaScript，无 TS**） | RuoYi-Vue3；Pinia；axios 拦截器；SSE 自研客户端；AI 页面 11 个 |
| 后台 | Java 8 / Spring Boot 2.5 / MyBatis / Druid / Redis / Maven 多模块 | :8080；RuoYi JWT 权限链；Agent 网关/配置/工具/模型/KB/MCP/评测/驾驶舱接口 |
| 运维端 | Java 11 / Spring Boot / MyBatis-Plus / JWT | :9070；独立签名密钥（fail-closed） |
| Agent | Python 3.11 / FastAPI / LangGraph / SQLAlchemy(async) | :8090；checkpoint 默认 SQLite，**当前本机用 PostgreSQL 17**；补货/诊断/助手/知识库/MCP |
| 存储 | MySQL（业务 + `agent_*`）/ Redis 3.2（令牌/验证码，不能承载 checkpoint）/ PG（会话 checkpoint） | 单主库；Redis 无 Streams/模块系统 |
| 集成 | Java→Python：HTTP + SSE（JWT+权限点）；Python→Java：REST 回调（服务间密钥+白名单+限流） | 全链路 `request_id` |
| 质量 | `dkd-parent` **434 tests** + `dkd-app` **16 tests** + pytest **818 passed/14 skipped** + ruff + 前端构建 + compose 校验 + agent-eval | 本地全绿；CI 5 个基础 job + 1 个离线评测 job（2 个 workflow） |

## 8. 现在能用到什么程度（如实）

**已可用（2026-11-04 工作区实测）**
- 组织/设备/商品/点位/货道/订单/工单/报表全套管理；
- 补货 Agent 闭环 + 工作台 + 暂停 + `llm_calibrated` 降级标记；
- 诊断 Agent（证据/未知项/结论卡片/派单确认）；
- **配置台**：自定义智能体、prompt/工具/模型档案、版本历史/回滚；
- **知识库 L2**：文档入库、检索测试、停用、引用强制校验、回退率统计；
- **MCP**：server 配置/探测/同步/只读工具调用（mock 验收通过）；
- **会话持久化/历史详情**：configVersion、工具耗时/行数、刷新恢复、重启恢复演练 PASS；
- **评测护栏 + 驾驶舱 + 告警检查 + 安全复核**：脚本/页面/报告齐备；
- 主业务兜底：`agent.enabled=false` 时仍可运行原规则链路。

**已知边界 / 未验项**
- **真实评测样本缺失**：评测集仅 8 条 example-only，无 `verified` 样本 → 取数准确率 ≥90%（5-2）、M5 质量达标（5-7）、
  效果评估（6-8）**无法评分**，未伪造结论；
- **MCP 真实 server/出网白名单未提供**：当前只完成 mock 验收；本期 transport 仅 http，工具只注入诊断场景；
- **知识库向量为本地哈希**（无外部 embedding），召回质量待真实语料评测；L3 案例库仍「未启用·数据未达标」；
- **成本对比/Agent vs 规则**：本机近 7 天 calls=0、对比 n=0，只能验口径，不能下业务结论；
- **告警触达/灰度观察/培训**：webhook 值班群、G1~G4 观察、回退演练、培训考核需真人（🧑）；
- **浏览器可视走查**：无 headless 浏览器驱动，页面验收需人工；
- **安全剩余项**：凭据轮换（OSS/MySQL/Redis/JWT/Druid）、MCP 真实白名单、生产角色授权待外部；
- 交易链路只覆盖平台入库路径；合作商分成未实现；库存/容量历史不一致待业务确认；
- 4-5 真机 50 轮会话未跑（成本）；token 预算为启发式估算；`/health` 工具计数为缓存快照；
- 写/未同步 MCP 工具调用返回 404（拒绝行为正确，与任务书 400 状态码有差异）。

## 9. 快速上手（本机，2026-11-04 实际使用）

```powershell
# 0) 基础设施：MySQL 3306 / Redis 6379 / PostgreSQL 17 5432（checkpoint）
# 1) Python 智能体（Windows 必须用 python -m app，不能用 uvicorn 直启，见 AGENTS §1）
cd dkd-agent
.venv\Scripts\python.exe -m app          # 或 uv run python -m app
# 2) Java 后台（用 .run/launch/backend.ps1；.run/RUNNING.md 记录 DSH 后台任务方式）
powershell -NoProfile -ExecutionPolicy Bypass -File F:\DKD\.run\launch\backend.ps1
# 3) 前端
cd dkd-vue
npm run dev                              # http://127.0.0.1，账号 admin/admin123
```

> 本机联调/重启细节见 `.run/RUNNING.md`；重新构建 Java 时注意 `.run/backendbuild` 镜像与 logback 路径补丁。
