## 4. 派生决策（本轮文档核对新增，属技术默认，可改）

| # | 事项 | 决策 | 为什么必须现在记 |

| D-1 | S7 校准/降级卡的数据源 | **当前不可算**：`calibration_notes` 只存在 LangGraph state、未落库；`agent_decision_log.input_context.calibrated` 只是 `bool(calibration_notes)`（有明细即为真），**不能当校准率**。S7 首版该卡显示「—（数据源待 5-6）」，5-6 落 `llm_calibrated` 标记后再启用 | 若拿现有字段硬算，会把“90% 校准率”这种假数报给业务；口径定义见 `docs/agent-metrics-dictionary.md` §2.4 |

| D-4 | 无数据源统计卡的展示纪律 | 沿用旧排期同类纪律：**没有数据源的卡位留「—」并标注“待接入”，不填演示数字** | 引旧排期对 S7 前身页面的同一要求；避免驾驶舱变成“好看但不可信” |
