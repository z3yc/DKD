# DKD 智能体接入项目 · 开发排期计划清单

> 依据：《DKD智能体接入方案-LangChain-LangGraph.md》V1.0 + 原型 V2（dkd-agent-prototype.html）
> 基准日：2026-09-21（周一）起排 · 每周 5 个工作日
> 团队配置：1 Python 工程师（主攻）+ 1 Java 工程师（兼职，约 30% 投入）+ 前端（兼职，约 30% 投入）+ 产品/项目（原型已定，兼职跟进验收）
> 关键路径：**P0-1 集成底座 → P0-2 补货 Agent → P0-3 诊断 Agent**；并行线：前端改造、安全整改

## 三、关键依赖与风险缓冲

| 风险点 | 影响任务 | 缓冲措施 |
| --- | --- | --- |
| 决策点未按时拍板（0-1） | 全链路 | **W1 周一必须开评审会**，未决项按方案默认值先行（人工确认/DeepSeek/同机部署） |
| Java 工程师兼职投入不足 | 0-6/0-7/1-3/2-5 | 网关与回调集中在 W1 完成编码，后续仅联调；接口契约先出文档冻结 |
| LLM 建议质量不达标 | 1-4/1-5 | 统计基线不依赖 LLM，LLM 仅做校准与理由生成——最坏情况退化为"可解释的规则增强版" |
| 真实设备样本不足 | 1-12 | 与规则版并行双跑延至 3 周（W5~W7），M3 期间继续采集 |
| 节假日顺延（10 月国庆 W3~W4 部分影响） | Phase 1 | 排期按自然周计，如遇假期整体顺延，M2 顺移但不压缩联调时间 |

## 四、每周节奏建议

- **周一**：15 分钟站会定本周验收点（对照上表"完成标准"）
- **每天**：Python/Java/前端各自更新任务状态（本清单可直接作为跟踪表）
- **周五**：里程碑内做半天联调 + 验收演示（M1/M2/M3/M4 均排在周五）
